# Toggle Design System

A toggle is a switch-like control that allows users to quickly alternate between two opposing states (on/off) with a single click or tap.

## Checklist

- **Context**: Explaining what the toggle will do
  A toggle should always be turning a function on or off, not between two opposing versions of a function e.g. hot or cold Consider toggles for straightforward decisions that have low risk implications
- **Transition**: A clear visual change of the toggle switching between different states
- **State**: How the button changes based on the interaction, examples below
  Contrast active and inactive with brand colour for active and keeping the inactive muted

## Documentation

### Default
Toggles are usually off by default. It allows users to explicitly opt in to the action, rather than being opted in automatically deceptively.
(diagram: https://framerusercontent.com/images/190qrEZThM3SoQsuknaZ2toNEkQ.svg)

### Active
Toggle is on meaning it is actively performing an action. The active state can utilise the brand colours to help it feel part of the UI.
(diagram: https://framerusercontent.com/images/HbdVpjU0yj7svQLdCoZ8T3dmUTI.svg)

### With label
The label should convey the action or state of the toggle being active. For example, the label stating 'silent mode' means if the toggle is active, silent mode is active.
(diagram: https://framerusercontent.com/images/2EjGJhP6erxoDblfcfsYXph8W7g.svg)
