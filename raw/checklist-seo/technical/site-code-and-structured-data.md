# Código do site e dados estruturados

## Checklist

- **HTTPS com certificado SSL válido** — sinal de ranking desde 2014; browsers modernos
  marcam sites sem HTTPS como "Not Secure", o que sobe a taxa de rejeição.
- **`hreflang`** no `<head>` de cada versão localizada, se o site serve vários
  países/idiomas — sem isto os motores podem servir a versão errada a quem procura.
- **Schema markup relevante ao tipo de conteúdo** (Organization, Product, Article, Event,
  Recipe, Review) no `<head>` — não é factor de ranking directo, mas activa rich results
  (CTR mais alto) e ajuda tanto motores de busca como sistemas de IA a extrair factos
  discretos (preços, autores, datas).
- **Validar o schema implementado** com uma ferramenta de teste de dados estruturados —
  não assumir que o código gerado está correcto.
- **Usar HTML semântico**, não só `<div>`/`<span>`: `<header>`, `<h1>`, `<nav>`, `<main>`,
  `<h2>`, `<footer>`. Agentes de IA interpretam a página lendo o HTML bruto (e tirando
  screenshots de renderização), apoiando-se na estrutura de acessibilidade — markup
  genérico não dá nenhum sinal sobre a estrutura da página.
